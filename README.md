- RP2040の評価F/Wの個人開発リポジトリ

## 開発環境

### デバッガ

- [Debugprobe on pico](https://www.raspberrypi.com/documentation/microcontrollers/debug-probe.html)
  - F/W ... [v2.3.1](https://github.com/raspberrypi/debugprobe/releases/tag/debugprobe-v2.3.1)

### H/W

- 基板
  - [RP2040 Zero🔗](https://www.waveshare.com/rp2040-zero.htm)
  - [Maker Pi RP2040🔗](https://www.cytron.io/p-maker-pi-rp2040-simplifying-robotics-with-raspberry-pi-rp2040)
- マイコン
  - [RP2040🔗](https://www.raspberrypi.com/products/rp2040/)
    - CPU
      - x2コア CPU (デュアルコア)
      - [Arm Cortex-M0+🔗](https://www.arm.com/ja/products/silicon-ip-cpu/cortex-m/cortex-m0-plus)
    - Clock
      - 200MHz or 133MHz
    - ROM
      - 2MB
    - RAM
      - SRAM: 264KB
